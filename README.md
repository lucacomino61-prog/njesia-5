# Njësia 5 · forumi i banorëve

A residents' forum for Tirana's Administrative Unit No. 5 (Blloku, Selita, Tirana e Re), built on the
ideas of rrugaelbasanit.forum with its audited bugs fixed. A residents' initiative, not an official
municipal site. Albanian at `/`, English at `/en/...`.

Stack: Astro 7 (server) on Cloudflare Workers, D1 (SQLite), Better Auth, GSAP + Lenis (one clock,
loaded on first interaction). Every action is a real form POST, so the site works before JavaScript.

## Run locally
```
npm install
cp .dev.vars.example .dev.vars   # then put your own secret and dev password in it
npm run db:migrate          # D1 schema (local)
node tools/seed.mjs         # SAMPLE content (see NEEDS_VERIFICATION.md)
npm run dev                 # http://127.0.0.1:3750
```
`.dev.vars` holds `BETTER_AUTH_SECRET` and `DEV_SEED_PASSWORD` (sign in as `banor1@shembull.test` …
`banor60@shembull.test`, or `ekipi1@shembull.test` for the team panel, with that password).
Accounts: sign-up (name, surname, phone, street, email) → 6-digit email code → team approval → can write.
Emails go to the local `dev_outbox` table in development and the code page shows the code.

## Checks
- `node tools/e2e.mjs` — 63 end-to-end checks of every write (resident; new account with email code, approval,
  phone sign-in, temporary password; team).
  It changes data; run `node tools/seed.mjs` again afterwards.
- Lighthouse, all page types, phone + desktop: `npm run build`, `npm run preview` (3751),
  `node tools/gzip-proxy.mjs` (3752, stands in for Cloudflare's compression), then
  `node tools/lh.mjs http://127.0.0.1:3752` (set `LH_CHROME` to a chrome-headless-shell if desktop
  Chrome reports NO_NAVSTART). Last run: 30/30 at 100 in Performance, Accessibility, Best Practices, SEO.
- Stop the preview before `npm run build` on Windows (it locks `dist/`).

## What is where
- `src/pages` — routes (`/forumi`, `/tema/[id]`, `/propozime/[id]`, `/vendime`, `/ngjarje`, `/live`,
  `/bizneset`, auth pages, `/profili`, `/njoftime`, `/ekipi/*` team panel, `/do/[action]` writes).
- `src/lib/actions.ts` — every write with its permission check. `src/lib/queries.ts` — every read;
  counts are computed from rows, never stored.
- `src/pages/index.astro` — the home page, kept plain on purpose: what the forum is + two buttons,
  "How it works" in 3 steps, the week in numbers, latest posts, poll + next meeting, team decisions.
- `src/lib/sentence.ts` + `src/components/LiveSentence.astro` — the week in short plain sentences;
  only the numbers are painted.
- `src/i18n/index.ts` — all copy, SQ and EN.
- `migrations/` — `0001_auth.sql` is generated by `node tools/auth-sql.mjs`; `0002_app.sql` by hand.

## Deploy (only when asked)
`wrangler d1 create njesia5` and `wrangler kv namespace create MEDIA` / `SESSION` (put the ids in
wrangler.jsonc), set `SITE_URL` and `ENVIRONMENT=production`, `wrangler secret put BETTER_AUTH_SECRET`
(+ Resend, required for email codes; Google optional), `wrangler d1 migrations apply njesia5 --remote`, decide on the
sample seed, then `npm run build && wrangler deploy`.
